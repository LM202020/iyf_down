# 领域术语表(Glossary)

本项目 fork 自猫抓 cat-catch。本表只收录 **iyf 多集下载模块**引入的领域概念,是团队沟通的统一语言(ubiquitous language)。**此处只定义"是什么",不写"怎么实现"**——实现决策见 `iyf-multi-download-design.md`。

---

**剧 / Series**
一部连续剧整体。在 iyf 中对应播放页 URL `/play/<剧key>` 里的那串 ID(如 `G3D93jBLAY4`)。一部剧包含有序的多集。

**集 / Episode**
剧的一集,是下载的最小内容单位。每集有自己独立的标识 `episode.key`,与剧 key 不同。

**剧 key / Series Key**
整部剧的唯一标识,出现在播放页路径 `/play/<剧key>`。**不是**分集标识。

**集 key / Episode Key**
单集的唯一标识。切集时体现在 `?key=<episode.key>`。遍历一部剧 = 遍历它的集 key 列表。

**镜像域名家族 / Mirror Host Family**
iyf 用一组结构完全相同的容灾域名对外提供同一套站点(iyf.tv、aiyifan.tv、dnvod.tv…)。对本模块而言,命中家族里任一域名的播放页,行为都一致。

**切集 / Episode Switch**
在播放页内从当前集导航到另一集的动作。本模块通过驱动页面(而非直接调后端接口)完成切集,使页面播放器自行发起该集的流请求。

**已鉴权流地址 / Authorized Stream URL**
页面播放器(hls.js)在真实播放时发出的 m3u8 / ts 地址。它天然携带该次会话的防盗链签名、过期时间(vendtime)和出口 IP 绑定,只在同一浏览器会话内、且在过期前有效。本模块下载的就是这种地址,不自行伪造。

**下载任务 / Download Job**
用户一次发起的"下载某部剧的选定若干集"的整体作业。一个任务包含多个集下载单元,有整体进度和可取消的生命周期。

**集下载单元 / Episode Download**
下载任务中针对单独一集的工作项:切到该集 → 取得已鉴权流地址 → 下载合并落盘。有自己的状态。

**集状态 / Episode Status**
一个集下载单元的生命周期取值:待下载、切集中、下载中、已完成、已失败。

**背压 / Backpressure**
限制同时进行的集下载单元数量的机制:活跃下载数达到上限前不再切下一集。目的是让每个已取得的流地址都能立即开始下载,避免其在等待中过期。

**补下 / Re-download**
任务结束后,针对被标记为"已失败"的集重新发起下载的动作。

**画质档 / Quality Variant**
同一集在不同清晰度下的一个版本(如 1080p / 720p)。一个下载任务对全部集统一选用一个画质档。
